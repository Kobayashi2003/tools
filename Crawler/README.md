# Crawler

Downloaders and local library managers for specific sites, one folder each.
Their ports are in [PORTS.md](PORTS.md).

| Project | What it does |
|---|---|
| [annas-archive-downloader](annas-archive-downloader/README.md) | Searches Anna's Archive and downloads the best file per volume |
| [fc2-sukebei-browser](fc2-sukebei-browser/README.md) | Crawler and web UI for FC2 torrents on sukebei |
| [google-play-comics-downloader](google-play-comics-downloader/README.md) | Console script that saves pages from the Google Play Books reader |
| [jable-downloader](jable-downloader/README.md) | HLS videos and covers from Jable.tv |
| [khinsider-downloader](khinsider-downloader/README.md) | Game soundtrack albums from KHInsider |
| [nhentai-downloader](nhentai-downloader/README.md) | Gallery images from nhentai and imhentai |
| [novelia-downloader-v2](novelia-downloader-v2/README.md) | Crawler and library manager for Novelia's light novels |
| [pawchive-downloader-v2](pawchive-downloader-v2/README.md) | Archives Pawchive and Fanbox creators |
| [tmw-downloader-v2](tmw-downloader-v2/README.md) | Searchable page over TMW Reading Club's Discord channels |
| [vgmdb-downloader](vgmdb-downloader/README.md) | Userscript that downloads every image on a VGMdb album page |
| [x-image-downloader](x-image-downloader/README.md) | Full-resolution images from X timelines |
