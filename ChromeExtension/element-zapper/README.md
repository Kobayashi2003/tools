# Element Zapper

Chrome extension that deletes page elements: hold the trigger key and click an element.

## Use

Hold the trigger key (Alt by default) and move the mouse; the element under it is outlined in red.
Click to delete it. **Ctrl/Cmd+Z** restores the last deletion, up to 100 steps.

The popup turns the extension on or off and sets the trigger: Alt, Ctrl, Shift, ⌘/Win, or a
recorded key. Deletions last until the page reloads.

## Install

`chrome://extensions` → Developer mode → **Load unpacked** → select this folder.
