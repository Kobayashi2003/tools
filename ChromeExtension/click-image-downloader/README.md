# Click Image Downloader

Chrome extension: hold a modifier key and click an image to download it.

## Use

Hold the trigger key (**Alt** by default; change it in the popup) and hover an image to outline
it. Where images overlap, scroll to cycle through them (the badge shows `1/N`), then click to
download. Works on `<img>` (respecting `srcset`), CSS background images, `<canvas>`, inline
`<svg>`, video posters and `blob:` images.

## Install

`chrome://extensions` → Developer mode → **Load unpacked** → select this folder.
