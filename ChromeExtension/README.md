# ChromeExtension

Chrome extensions, one folder each, sharing one pnpm root for lint and format.
None listens on a port.

| Project                                                    | What it does                                          |
| ---------------------------------------------------------- | ----------------------------------------------------- |
| [click-image-downloader](click-image-downloader/README.md) | Hold a modifier key and click an image to download it |
| [element-zapper](element-zapper/README.md)                 | Hold a key and click to delete page elements          |
| [page-screenshot](page-screenshot/README.md)               | Visible-area or stitched full-page screenshots        |
| [resource-grabber](resource-grabber/README.md)             | Collects resource URLs from every frame of a page     |
| [tab-deduper](tab-deduper/README.md)                       | Closes duplicate tabs across windows                  |
| [x-quick-actions](x-quick-actions/README.md)               | Gestures on X media to download, like, or both        |
