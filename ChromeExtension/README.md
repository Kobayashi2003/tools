# ChromeExtension

Chrome extensions, one folder each. None listens on a port.

| Folder | What it is |
|---|---|
| [click-image-downloader](click-image-downloader/) | Hold a modifier key and click an image to download it |
| [element-zapper](element-zapper/) | Hold a key and click to delete page elements |
| [page-screenshot](page-screenshot/) | Visible-area or stitched full-page screenshots |
| [resource-grabber](resource-grabber/) | Collects resource URLs from every frame of a page |
| [tab-deduper](tab-deduper/) | Closes duplicate tabs across windows |
| [x-quick-actions](x-quick-actions/) | Gestures on X media to download, like, or both |
