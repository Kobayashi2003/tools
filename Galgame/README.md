# Galgame tools

Utilities for visual novels. Each tool owns its dependencies, build configuration, and development checks.

| Project | What it does |
| --- | --- |
| [NNN Voice Continue](nnn-voice-continue/README.md) | Generates dialogue voice-continuation patches for supported NNN engine games. |
| [JINKI -Unlimited- Gallery](jinki-unlimited-gallery/README.md) | Generates the CG and replay gallery patch for the supported Windows release. |
| [JINKI -Unlimited- Voice Continue](jinki-unlimited-voice-continue/README.md) | Generates the dialogue voice-continuation patch for the supported Windows release. |
